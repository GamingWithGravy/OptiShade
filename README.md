# OptiShade Core 1.0.96

Signed OptiShade Core package for the OptiShade launcher. The launcher reads [`channel.json`](channel.json), checks its signature, then downloads and verifies `packages/OptiShade.Core-1.0.96.tar.gz` and every file in it before installing.

Changes in 1.0.96:
- The in-game OptiShade menu shows version 1.0.96, matching the launcher. No other changes.

Includes every change from 1.0.78, 1.0.93, 1.0.94 and 1.0.95.

`packages/OptiShade.Core-source.tar.gz` is the corresponding source for the GPL-covered OptiScaler-derived portions. The launcher and installer are not included here.
