# OptiShade legacy downloads

**Status: verified public legacy EXEs not yet staged.**

This branch is reserved for older public OptiShade EXE downloads only. It will contain no source, installer or launcher. No executable is currently published here.

The EXEs currently found in the local `Beta/dist` folder are rebuilds labelled R347–R370 and their verification receipts mark them `PrivateTesting=true`. They are not being presented as public legacy releases. Only confirmed public release EXEs will be added, with their original version, SHA-256 and provenance.

Future large EXEs use Git LFS. Check the branch manifest and hash before downloading. Do not use private test builds as public releases.
