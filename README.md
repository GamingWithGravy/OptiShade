# OptiShade Core — Stable component channel

**Status: package not published — available tomorrow.**

This branch is reserved for independently versioned OptiShade Core packages. There is no installer, launcher or component binary in this branch yet. Do not download or install this README as a package.

The first Core package must include the runtime files required for the selected component version, a signed compatibility manifest, hashes, rollback metadata, and all licence notices. Because the Core runtime contains GPL-covered OptiScaler code and modifications, the matching corresponding source must be available with any redistributed binary. Core publication is blocked until that exact source and file inventory are reviewed.

The stable feed will be enabled only after the local test client can verify and apply the package transactionally.
