# OptiShade Core 1.0.94

Signed OptiShade Core package for the OptiShade launcher. The launcher reads [`channel.json`](channel.json), checks its signature, then downloads and verifies `packages/OptiShade.Core-1.0.94.tar.gz` and every file in it before installing.

Changes in 1.0.94:
- The in-game "update available" notice now compares your installed Core with the Core update the launcher offers. It no longer appears when you are already up to date.
- The in-game OptiShade menu shows version 1.0.94.

Includes every change from 1.0.78 and 1.0.93.

`packages/OptiShade.Core-source.tar.gz` is the corresponding source for the GPL-covered OptiScaler-derived portions. The launcher and installer are not included here.
