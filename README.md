# Intel XeSS support 1.0.77

Signed Intel XeSS runtime package for the OptiShade launcher ("FSR / XeSS support" on the Components page). The launcher reads [`channel.json`](channel.json), checks its signature, then downloads and verifies `packages/OptiShade.Providers.Intel-1.0.77.tar.gz` and every file in it before installing.

The XeSS runtime files are Intel's unchanged redistributables. The launcher and installer are not included here.
