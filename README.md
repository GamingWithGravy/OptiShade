# OptiShade Image Effects 1.0.77

This branch provides the stable Image Effects package for download-channel validation. Remote installation and rollback are not enabled, so the package is deliberately marked `installable: false`.

The archive contains the bundled effect shaders, textures, presets and the applicable notices. Its package inventory and SHA-256 are listed in [`manifest.json`](manifest.json).

The launcher and installer executables are not included here or in Releases.
