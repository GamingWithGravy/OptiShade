# AMD FidelityFX support 1.0.77

Signed AMD FidelityFX runtime package for the OptiShade launcher ("FSR / XeSS support" on the Components page). The launcher reads [`channel.json`](channel.json), checks its signature, then downloads and verifies `packages/OptiShade.Providers.AMD-1.0.77.tar.gz` and every file in it before installing.

The FidelityFX runtime files are AMD's unchanged redistributables. The launcher and installer are not included here.
