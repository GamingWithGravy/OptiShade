# OptiShade Core 1.0.93

Signed OptiShade Core package for the OptiShade launcher. The launcher reads [`channel.json`](channel.json), checks its signature, then downloads and verifies `packages/OptiShade.Core-1.0.93.tar.gz` and every file in it before installing.

Changes in 1.0.93:
- The in-game OptiShade menu shows version 1.0.93, matching the launcher.

Includes every change from 1.0.78.

`packages/OptiShade.Core-source.tar.gz` is the corresponding source for the GPL-covered OptiScaler-derived portions. The launcher and installer are not included here.
