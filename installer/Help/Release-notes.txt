OptiShade Manager 0.20.2

- Fixed missing Windows PowerShell module discovery in the embedded update helper.
- Added free-space checks before download, extraction and game-file updates, with clear low-disk-space errors.
- Added staged update validation: the downloaded installer is checksum-verified, extracted and its complete payload checked before the working installer is replaced. Recorded game installations and original backups are checked first too.
- Added a separate completion receipt for each update stage, retained process handles and fresh error reporting so an unconfirmed stage cannot be reported as successful.
- The updater requests administrator access before applying changes. Cancelling UAC keeps setup open.
- Renamed the user-facing application OptiShade Manager. Existing update filenames remain compatible.
- Restyled the patch-notes popup with a dark draggable header, rounded controls and matching scrollbar.
- Cleaned up the updater to match the startup splash, with stage progress, scrollable error details, Update complete and Open manager / Close buttons. It stays open until you choose.
- The old application recovery copy is removed after the entire update succeeds. Failed updates retain it for recovery.
- The manager remains at its existing location. Presets and configuration are preserved during game-file updates.
- Includes 0.20.1 improvements: immediate installation-label refresh, version in the in-game header, clean original-file backup handling, full-width top drag area and dismissible patch notes.
- Automatic update checks remain available in setup and in game, alongside the manual Check for updates button.

Use Check for updates in the manager. Updates started from older versions still use that version's updater interface; the full staged workflow is used for updates started from 0.20.2 onward. The 0.20.2 game-update helper also validates its payload when invoked by an older updater.

Neural rendering starts off by default. The extended pass limit remains five. TAA neural rendering remains Coming soon (INOP).
