OptiShade Manager 0.20.4

- Setup now shows Already installed and disables Install for installed copies, including installations with optional downloads still pending.
- Incomplete installations show Repair required instead of allowing another normal installation.
- Repair, Restore, troubleshooting and unfinished-download recovery remain available.
- The Install button refreshes after actions, when switching installations and when changing the game directory. Restoring enables installation again.
- Added a second installation-state check when Install is clicked to prevent an accidental reinstall if the state changed after the screen loaded.
