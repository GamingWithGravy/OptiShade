# OptiShade 0.21.3-beta.4 Beta

**X-PLANE 12 VULKAN STARTUP FIX**
- Fixed the packaged Vulkan layer's Windows DLL path. Forward-slash relative paths could fail to load ReShade64.dll and surface as VK_ERROR_OUT_OF_HOST_MEMORY during vkCreateInstance.
- Verified the failure and corrected startup with the actual packaged DLLs in an isolated Vulkan instance test. A full cockpit test on affected systems is still needed.
- Play now validates the layer JSON, resolved DLL and recorded component hashes before launching. Invalid installations produce a repair/update message instead of forcing a broken layer.
- Preserves inherited Vulkan layer paths and other requested layers, removes duplicate entries, and handles existing VK_LAYER_PATH overrides correctly.
- All launch environment changes stay inside the child process. No driver changes or system-wide Vulkan registration.
- Play explains when administrator mode prevents local Vulkan layer discovery. Reopen the manager normally before launching X-Plane.
- X-Plane launch diagnostics now record validation, sanitized layer configuration and component hashes.

**BETA TO STABLE**
- Increased the previous-manager cleanup wait from 2 to 30 seconds so a closing beta launcher can finish releasing its EXE. The update window remains responsive.
- Only the exact unchanged previous EXE is removed. If another process still holds it open, the completion message shows its retained location.
- This cleanup applies to switches started by Beta 4. Manually opening a separate stable installer does not remove other downloaded EXEs.
- Return to stable continues to select the latest published stable release and turns beta opt-in off after success.

**INSTALLING**
- Close your simulators, enable beta versions in Settings, then Check for updates.
- If updating manually, run Beta 4 and update the recorded X-Plane installation in Setup before Play. Repair is for installations already on the matching version.
- Presets and configuration are preserved. MSFS functionality and stable 0.21.3 are unchanged.
- The existing dxgi.dll bridge remains required for the XP12 menu and experimental NR integration. Do not delete it manually; Restore uses ownership records and backups.
- Use Play in the manager for X-Plane. TAA NR, Vulkan and XP12 remain experimental beta features.

**DOWNLOADS**
- One beta EXE and one portable ZIP. Choose one; portable users should preserve their Data folder when extracting the new version.
