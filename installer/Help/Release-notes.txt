# OptiShade 0.21.1 EMERGENCY UPDATE

**IMPORTANT**
- Release 0.21 has been withdrawn following reports of instability.
- XP12 installation and experimental TAA/Vulkan Neural Rendering are removed from this emergency build. MSFS 2020/2024 image effects and supported DLSS-based NR remain available.

**FIXES**
- Added GPU-memory checks before and during NR. NR stops submitting work when memory headroom is too low or the graphics device has failed; restart the simulator after a failure.
- NR tuning waits for sliders to settle and the previous model to retire before rebuilding, reducing repeated model allocations.
- Improved Xbox/WindowsApps folder detection and guidance for selecting the actual simulator installation folder.
- Generated graphics logs no longer block updates as untracked loaders. Changed or unknown graphics DLLs still stop installation and are identified in the message.
- Added memory-budget details to NR logs. These are safeguards and possible fixes; the reported MSFS crashes are not yet confirmed resolved on affected systems.

**ROLLBACK**
- A permanent Revert update button is below the update controls. Select a supported previous build and press Install selected build to download, verify and install it automatically.
- Presets and configuration are preserved. The selected manager EXE is saved to your Desktop.
- Close all simulators first. Automatic rollback currently supports the regular EXE workflow and published compatible builds from 0.20.12 onward. Withdrawn releases are not listed. Portable users must use a separate older portable package. XP12 must be restored before reverting to a version that does not support it.

**INSTALLING THIS UPDATE**
- Close MSFS and use the update workflow, or run this EXE and choose Update OptiShade for your installation. A restore/reinstall is normally not required. Repair only repairs the matching installed version.
- Existing XP12 installations are not updated or automatically removed. To remove 0.21 from XP12, use Restore original files in the existing manager before moving to a future beta.

**STABLE AND BETA**
- main is the stable release branch. Experimental XP12, TAA and Vulkan work continues separately on beta.
- The next beta patch will be published separately on GitHub Releases and marked Pre-release; no new beta download is being published with this emergency update. Settings now includes Opt into beta versions for testing, off by default. Enable it to see compatible prereleases in update checks; installation still requires your choice.
- Keep a future beta manager in a separate folder, for example Desktop\OptiShade Beta. A separate manager folder does not isolate the game installation: do not install stable and beta over each other in the same game folder. Follow the beta release's migration instructions.

**ANTIVIRUS NOTICE — SUSPECTED FALSE POSITIVES**
OptiShade's unsigned installer extracts a helper and graphics components; its in-game features use graphics hooks. These behaviours can trigger heuristic antivirus alerts in legitimate software, but do not prove that any individual detection is a false positive. The reported 0.20.12 VirusTotal result flagged two vendors; its matching installer and helper scanned clean locally with Microsoft Defender. Vendor confirmation is still needed. Download only from the official GitHub releases. If blocked, report the exact detection and file path; do not disable antivirus or add blanket exclusions.
