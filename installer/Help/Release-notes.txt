NEXT PATCH - LOCAL PREVIEW

NEW FEATURES
- Permanent Revert update button: choose a supported older build and install it automatically, keeping presets and settings. Incompatible X-Plane downgrades are blocked.
- SnapShot: assign a key in the manager or in-game Keybinds. Saves one PNG with your rendered effects to Optishade Snapshots in the game folder, then shows a notification.
- Browse screenshots from the manager or in-game UI.
- Choose what to keep when uninstalling: app files, INI presets and snapshots. Remove everything requires confirmation.

FIXES
- Added NR GPU-memory checks at startup and during use, plus device-failure protection and memory details in logs. These safeguards may help with NR-related failures; the reported MSFS crashes remain under investigation.
- NR tuning waits for sliders to settle and the previous model to retire before rebuilding, reducing repeated allocations while adjusting settings.
- X-Plane Play now supplies its required ReShade launch argument.
- Generated graphics logs no longer block automatic updates as untracked loaders. Conflicting DLLs still stop the update and are now named in the message.

ANTIVIRUS NOTICE - SUSPECTED FALSE POSITIVES
Some antivirus products may flag OptiShade. The installer extracts a helper and graphics components, and the in-game features use graphics hooks. These behaviours, together with an unsigned executable, can trigger heuristic detections in legitimate software; they do not prove the cause of any particular alert.

The reported 0.20.12 VirusTotal result shows detections from Bkav Pro and Trapmine. The matching official installer and its FusionSetup.exe helper had no detections in our local Microsoft Defender checks on 27 September 2026. Vendor confirmation is still needed, and a clean scan is not a guarantee.

Download only from the official GamingWithGravy/OptiShade GitHub releases. If a file is blocked, leave it blocked and report the antivirus name, detection name, affected file path and OptiShade version in BlackBox Discord. Do not disable your antivirus or add blanket exclusions.

OPTISHADE 0.21 XP12

EXPERIMENTAL RELEASE
X-Plane 12
- Install, repair, restore and launch X-Plane 12 from OptiShade.
- Launch X-Plane using Play in OptiShade to load its Vulkan layer.

EXPERIMENTAL FEATURES
TAA support
- Optional Neural Rendering with native TAA in MSFS DirectX 12. Enable TAA neural guides in Image effects, then enable the experimental TAA option and NR in Neural rendering.
- SDR only, up to 3840x2160, with frame generation off. Native 4K TAA NR has been visually tested in MSFS 2020 and 2024 on an RTX 5090, with no shimmer reported in the final tests. Support remains experimental.
VULKAN support
- Image effects and optional Neural Rendering in X-Plane 12 without a built-in DLSS option. Enable the neural guide technique before NR. NR starts off each launch.
- Experimental NR still requires a compatible RTX GPU and model. This does not add DLSS upscaling or frame generation to X-Plane.
VR support
- Experimental compatibility testing. Headset rendering, stereo NR and VR frame generation have not been validated for this release. Desktop test results do not confirm headset support; please report your headset, VR runtime and simulator settings with diagnostics.

FIXES
- Improved simulator folder detection and invalid-path handling.
- Corrected Vulkan NR setting delivery to the model.
- Added safeguards for unsupported Hold Frame textures and allocation failures.
- Corrected frame-limit updates and fallback handling when using the XeLL limiter.
- Repair now uses only the matching installed version. Updating is a separate action.
- Preset selection checks for missing FX before loading a look.
- FX and ZIP imports no longer require discarding unsaved preset edits.

IMPROVEMENTS
- Diagnostics export asks you to describe the issue and includes your report in the ZIP.
- Diagnostic ZIPs save to Desktop with an Open file location confirmation.
- Expanded crash, rendering and import-failure evidence in diagnostics.
- Import errors include background-helper startup failures; failed downloads keep the previous look selected.
- Optional experimental RTX 40 MFG component setup for compatible native DLSS frame-generation paths. Disabled by default; results depend on the game and hardware.
- Portable manager download: extract it and keep its Data folder when updating.
- Regular manager updates place the new EXE on Desktop and show its location.
- Updated troubleshooting styling and developer information.

UPDATING
Close the simulator, open this manager, select the existing installation and choose Update OptiShade. No Restore or uninstall is normally needed. Saved presets, settings and original backups are preserved. Repair is for the same version only. For X-Plane, use Play in OptiShade after installation.
