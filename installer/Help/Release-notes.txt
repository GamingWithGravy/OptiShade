# OptiShade 0.21.3-beta.2 — Local test candidate

This build is experimental and has not been published. Keep 0.21.2 Stable available. Do not use this candidate for an important flight.

EXPERIMENTAL FEATURES
- X-Plane 12 Vulkan image effects and Neural Rendering. Launch XP12 using Play in this manager. Frame generation is not provided for XP12.
- MSFS 2020/2024 TAA Neural Rendering using estimated guides. Use SDR with frame generation disabled. NR and TAA fallback require a fresh opt-in each game session.
- These paths passed earlier local visual checks, but this final candidate still needs a fresh cockpit check. Performance and compatibility vary.

NEW FEATURES AND FIXES
- SnapShot: assign a key in the manager or in-game Keybinds. One PNG is saved in the game's Optishade Snapshots folder, followed by a completion notification. Browse screenshots opens that folder.
- Snapshot storage resolves Xbox installation aliases. Cleanup records are verified before success is reported; unrelated pictures are not removed.
- Capture requests stay with the active effects runtime instead of a different game window.
- Selective uninstall lets you remove app files, saved INI presets or recorded snapshots. Remove everything requires confirmation. Snapshot cleanup is restricted to games recorded by this manager.
- Beta build labels, saved update-channel preference and channel-correct download links. Beta revision numbers are compared numerically for upgrades and same-version repair.
- Generated graphics logs no longer block updates. Changed or untracked graphics DLLs still require review.
- NR memory-budget checks and tuning debounce are retained. TAA waits use completion events and log synchronous frame cost; the GPU safety barriers remain in place.
- XP12 launch includes its ReShade compatibility argument.

**FIXES**
- Added on-demand downloads for three older Barbatos shader filenames used by Vapory presets, with pinned original sources and integrity checks.
- Restore/uninstall now preserves changed, recorded shader source files in %LOCALAPPDATA%/OptiShade-Recovery before removing them from the game. Changed DLLs still require review.
- Fixed in-game INI/ZIP imports failing when MSFS is launched through its WindowsApps link. Imports resolve the physical game folder; unsafe archive paths and linked shader folders remain blocked.
- Fixed conflicting optional-MFG ownership records that could prevent restoring version.dll. Original backed-up files are preserved.
- Added a check for a missing upscaler backend before evaluation. The reported MSFS crashes remain under investigation; this is not a confirmed fix for every crash.
- Improved the missing/damaged installer-file message with recovery steps. Damaged or missing DLLs still fail verification.

**IMPROVEMENTS**
- Retry NR after a memory-pressure pause without restarting the simulator.
- Added a memory-pressure override beside Apply the model. It is off by default and lasts only for the current game session. Low VRAM can still cause stutters or crashes; device-loss checks remain active.
- Compatible RTX 40 installations automatically receive the bundled MFG component. Native DLSS Frame Generation must still be enabled in game; Backspace opens its menu. Supported multipliers vary. Existing conflicting loaders are not overwritten by automatic MFG setup.
- Other GPU families retain their supported options; this build does not install an unvalidated RTX 40 component on RTX 20/30/50, AMD or Intel.
- Beta opt-in and uninstall choices now use purple toggle switches.

SWITCHING VERSIONS
- Enabling beta in Settings changes eligible downloads, not installed files. No public prerelease is available for this candidate.
- Restore XP12 original files before returning to stable. Stable does not support the XP12 installation.
- Use Revert update for available stable releases. Close all simulators first. Portable version changes use a separate downloaded package.
- Keep preset and manager-data backups. Separate manager folders do not isolate files installed into the same game.

KNOWN LIMITATIONS
- TAA and Vulkan NR use estimated guides and synchronous GPU work. Low FPS, stalls or image artefacts remain possible; live testing is required.
- No promise of AMD NR, universal game support, VR compatibility or a particular MFG multiplier is made by this beta.
- Some antivirus providers are flagging OptiShade. I've submitted a sample to Bitdefender for review and I'm investigating what's triggering the warnings. Thanks for your patience.
