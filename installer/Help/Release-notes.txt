OptiShade 0.21.4 Stable

**Stable**
- Fixed menu size and position not being remembered.
- Improved controller support and hotkey recovery. Added an option to separate keypad navigation keys.
- Fixed Print Screen binding for SnapShot. Added clearer key labels, conflict messages and Num Lock guidance.
- Improved preset import status when effects are missing or fail to load.
- Fixed restore being blocked by changed logs and improved repeat MFG installation.
- MFG controls are now available inside the OptiShade UI.
- Improved old installer cleanup when switching between stable and beta. Update downloads remain compatible with 0.21.3.
- Beta updates stay on beta. Return to stable checks for the latest stable release.
- Reduced repeated upscaler error pop-ups and improved diagnostics.
- Clearer installer errors when antivirus removes or blocks a file.

**Antivirus update**
- Bitdefender confirmed the submitted sample was clean. I am investigating the newer Windows Defender reports.
