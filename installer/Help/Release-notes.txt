OptiShade Manager 0.20.7 - MSFS 2020 experimental testing

MSFS 2020 - first experimental release
- This is the first public release enabling Microsoft Flight Simulator 2020 for testing. Support is experimental, not a guarantee of compatibility across systems.
- Tested successfully in MSFS 2020 Steam on an NVIDIA GeForce RTX 5090. Game logs confirm the DLSS input connection, Neural Rendering model initialization and active rendering at 3840 x 2160, including two-pass operation.
- Xbox / Microsoft Store startup and older RTX Neural Rendering have not yet been confirmed on real systems. Frame generation and triple-monitor stability are not certified by this test.
- Enable the Microsoft Flight Simulator 2020 (test) Home button, styled consistently with the 2024 button.
- Discover and distinguish FlightSimulator.exe from FlightSimulator2024.exe. Each simulator keeps its own install path, receipt, settings and restore backups.
- Steam uses the main executable and DXGI loader. Xbox copies use the launch helper when present; accessible legacy main executables can also be selected. Protected WindowsApps folders are not unlocked or modified through permission bypasses.
- Include both simulator process names in close-before-change checks, diagnostics and update handling.
- Show the selected simulator in Setup and the installation selector. Home installation labels and detection messages are separate for 2020 and 2024, with each detection message above its matching button.
- Test DX12 and DLSS first. Effects, upscaling, optional Neural Rendering and frame generation must be tested separately.

Older RTX compatibility attempt
- Add Prepare older RTX test under Setup > Advanced options and downloads.
- Reuse the existing pinned, hash-verified community RTX 20/30/40 compatibility model and verified companion NVIDIA runtimes. No new model is bundled and no native older-RTX neural support is claimed.
- Reject ambiguous multiple-RTX model selection and RTX 50 use of this test button.
- Preparation sets one pass, disables extra-pass unlocking and keeps Neural Rendering off. Other picture settings and keybinds are preserved.
- The in-game control for a matched older RTX device is labelled as an experimental compatibility attempt. Enabling it starts at one pass; runtime initialization determines whether it can run.
- The RTX 5090 / RTX 50 model path remains unchanged. Older RTX behavior still needs an actual older-card test.

Included compatibility foundation fixes
- Swapchain identity and retirement tracking, secondary-window isolation, corrected GPU-idle waits before resize cleanup, and null queue-array rejection in both native layers.
- D3D12 frame-device validation and actual rendering-GPU reporting.

Please report issues with your simulator edition, GPU, graphics API and diagnostics. Experimental support will improve with further testing.
